# Review the change at its actual scope

Every revision runs the EOD checker. Compare the changed public text with the last reviewed version and read its adjacent sentences before choosing the review scope.

| Change | Review |
|---|---|
| Formatting, typo, or the reader's already-confirmed name for a service | Local correction check; previous reviews still apply |
| Roger explicitly removes an ask because its owner is already handling it | Remove the ask, check nearby wording for dangling references, record the ownership/disposition; previous reviews still apply |
| A new or changed factual claim, status, promise, deadline, substantive ask, PR coverage, or sensitive detail | Both reviewers run a focused delta review |
| New mode, substantial rewrite, or changes whose effects span the whole update | Full review by both reviewers |

If a supposedly local edit changes factual meaning or hides a missed commitment, use the delta path. A formatting request does not authorize rewriting the story.

For a delta review, provide both the old and new passage, the affected sources, and enough surrounding text to check consistency. Ask for newly introduced or changed risks only. The reviewer may expand scope if it names a concrete cross-section consequence; uncertainty alone is not a reason to repeat the whole review.

Keep `## Review dispositions` in today's notes: the flag, Roger's answer or decision, and `open`, `fixed`, or `closed by Roger`. Send relevant dispositions to both reviewers. A closed flag reopens only when the reviewer identifies new contradictory evidence, not because the same suggestion is still absent from the copy.

Keep previous unresolved flags recorded. On a small follow-up, report the edit and new or changed flags; don't print the unchanged advisory list again. For local edits, use "Reviewer: previous review still applies (local correction checked)" and the same Reader status. For delta reviews, name the scope in their status lines. A user choosing not to add a checkpoint is not permission to invent one.
